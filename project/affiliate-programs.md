## Read this first — accuracy caveat

Every rate below comes from **third-party affiliate-roundup articles indexed in search**, not
from the merchants' own terms. I could not open the merchant pages: the network proxy in this
environment blocks them. Commission rates, cookie windows and even network membership change
often and are frequently reported wrongly in roundups.

**Treat every number as "verify on the application page."** Nothing here is confirmed, and I
have not invented any figure to fill a gap — where a rate was not stated, the cell says so.

1. **Register with Impact and ShareASale now.** Both accept new sites readily.
2. **Apply to Shop Indoor Golf and SkyTrak now** — direct programs, and this is the cluster
   worth building first.
3. **Publish 8–10 genuinely useful pages, including `/gear/how-we-test/`.** Do this before
   applying anywhere that reviews manually.
4. **Then apply to AvantLink, Callaway, TaylorMade, Global Golf, Austad's, Bushnell, Arccos.**
5. **Add Amazon Associates last**, purely as fallback coverage for products with no direct
   program.

## Rules we will hold to when these links go in

Recorded now so they are not negotiated later under revenue pressure:

1. **Commission never changes a ranking.** If the 3% product is better, it goes first. The
   Phase 6 integrity rule is not optional.
2. **Disclosure above the first affiliate link**, not only in the footer, plus a linked
   `/affiliate-disclosure/` page.
3. **`rel="sponsored nofollow"`** on every affiliate link.
4. **No affiliate link replaces a citation.** If a claim needs a source, it gets a source.
5. **No fabricated links.** A product with no program gets a plain unlinked mention.
6. **Every affiliate destination is logged** in `external-link-approval.md` and requires your
   sign-off before it goes live (Gate 5).
7. **Nothing gets reviewed as "tested" unless it was tested.** `/gear/how-we-test/` will state
   plainly which recommendations are hands-on and which are research-based. This is the single
   biggest trust advantage available over both competitors, and it only works if it is true.
